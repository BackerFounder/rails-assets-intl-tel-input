# rails-assets-intl-tel-input

> The Bower package inside a gem

This gem was automatically generated. You can visit [rails-assets.org](https://rails-assets.org) for more information.

## Usage

此 repo 為 rails-assets.org 產生的 13.0.4 版本備份（已移除 `rails-assets-jquery` 依賴），改由 GitHub 引用：

```ruby
gem "rails-assets-intl-tel-input", github: "BackerFounder/rails-assets-intl-tel-input", tag: "v13.0.4"
```

Then, import the asset using Sprockets’ `require` directive:

```js
//= require "intl-tel-input"
```
